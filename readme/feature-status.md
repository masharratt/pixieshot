# Feature Status (masharratt/flameshot fork)

**Last Updated:** 2026-10-18 (Animate button exports the Beautify look over a looping animated background)

| Token | Meaning |
|-------|---------|
| `prod` | Live, verified, in daily use. |
| `beta` | Feature-complete, under verification. |
| `dev` | In development. |
| `stub` | Scaffold only. |
| `deprecated` | Scheduled for removal. |

Plan: `planning/PLAN_sharex_fork.md` (local, not committed).

| Feature | Status | Description | Dependencies | Known Limitations |
|---------|--------|-------------|--------------|-------------------|
| Upstream capture + editor | prod | Flameshot 14/15 region capture with annotation editor. | Qt 6 | Editor must finish before capture is saved. |
| Unit test harness | beta | QtTest executables registered with CTest under `tests/unit`. | Qt6::Test | Covers strfparse, ruler math, capture-first request, toast stacking, window picking, history store, action lists, hotkey helpers and image effects. |
| Capture-first workflow | beta | Hotkey and tray captures save and copy on selection release, then show a toast with Edit, Copy, Pin and Show in Finder. Edit opens a normal window with a fixed toolbar on the active Space. Option `captureFirst`, default on. | Unit test harness | Edit window has no Dock icon. Esc closes it only when the canvas has focus. |
| After-edit thumbnail | beta | Saving from the editor shows a small picture of the result in the bottom-right corner. Left click reopens it in the editor, right click closes it, dragging drops the file into another app. | Capture-first workflow | One at a time. Closes after `editedThumbnailSeconds` (default 4, 0 = until closed), paused on hover. User confirmed it shows after an editor save (2026-10-14). |
| Hover window detection | beta | Picker shows a dotted outline around the window under the cursor, or the whole screen when no window is there; a click captures it, a drag over 4 px draws a region. No purple help box in picker mode. Option `hoverWindowDetection`, default on. | macOS CGWindowList | macOS only. |
| Capture history | beta | Every save is logged to history.jsonl; a thumbnail window (tray item or Cmd+Shift+Y) offers Open, Edit, Edit again, Copy, Show in Finder and Remove. Option `captureHistoryMax`, default 500. | Capture-first workflow | Not yet checked by hand. Editing an image larger than the screen saves a numbered copy. |
| Per-hotkey after-capture actions | beta | TAKE_SCREENSHOT and CAPTURE_AND_EDIT each run a configurable action list (save, copy image, copy path, open editor, pin, effects, toast) set on the Workflows tab. Hotkeys re-register live when changed. | Capture-first workflow | Not yet checked by hand. |
| Image effects | beta | Border, rounded corners and drop shadow applied by the Apply Effects action, configured with a live preview on the Workflows tab. | Per-hotkey actions | Not yet checked by hand. Effects needing transparency save as PNG only on the workflow save path. |
| Beautify | dev | Toolbar button and "Beautify every capture" option add a background, padding and shadow. Overlay: finishes like Accept. Editor: beautifies in place, window stays open, press again or undo reverts. Set on the Workflows tab. | Image effects | Not yet checked by hand. Editor Beautify flattens annotations until undone. Save dialog path ignores the JPEG to PNG switch. |
| Beautify size presets | dev | Option `effectAspect` grows the Beautify canvas to 1:1, 16:9, 9:16, 4:5 or 4:3 without cropping; `effectAutoBalance` first trims uneven blank margins from the capture. Set on the Workflows tab. | Beautify | Not yet checked by hand. |
| Beautify glass frame | dev | Option `effectGlass` draws a Liquid Glass bezel (`effectGlassPx`, 4-64 px) between background and shot: refracted blurred background, white tint, specular rim, hairline. Shadow falls under the bezel. Stills and recording export match. | Beautify | Not yet checked by hand. CPU only; ~300 ms for a 4000x3000 capture with shadow. |
| Beautify shot backgrounds | dev | Background "From screenshot" fills the canvas with the shot blurred, saturated and darkened. `effectAutoColors` picks the gradient colors from the shot. `effectGrain` adds noise to the background. Recordings use the first exported frame. | Beautify | Not yet checked by hand. Auto colors only applies to Gradient. |
| Animated backgrounds | dev | Animate button (macOS) saves the Beautify look over a looping Aurora, Gradient shift, Blobs or Twinkle background as MP4 and/or GIF next to the capture, with toast, history entry and file URL copied. Overlay also saves the still. Set on the Workflows tab. | Beautify, GIF / MP4 recording | Not yet checked by hand. GIF ~6 MB for 5 s. Editor Animate after Beautify nests the frame. |
| Re-editable screenshots | dev | Annotated captures keep a project (base image plus annotations) with their history entry. Edit again, the after-edit thumbnail and the toast reopen it with objects still editable; the editor can Save and Open .fsproj files. | Capture history | Not yet checked by hand. Project files are kept until the history entry is trimmed or removed. |
| Capture timer | dev | Option `captureDelaySec` (0 to 10) shows a countdown before hotkey and tray region captures start. Click the countdown to cancel. CLI --delay wins; recordings are not delayed. | Capture overlay | Not yet checked by hand. |
| Copy Text (OCR) | dev | Toolbar button reads the text and any QR code in the selection with Apple Vision, copies it to the clipboard and closes the capture. | macOS Vision framework | Not yet checked by hand. macOS only, hidden elsewhere. QR path has no automated test. |
| Ruler tool | beta | Editor tool that draws a measured line labelled with length and width x height in physical pixels. | Tool system | Not yet checked by hand in the running app. |
| GIF / MP4 recording | dev | RECORD_MP4 and RECORD_GIF hotkeys (and tray items) pick an area, record it with ScreenCaptureKit, and save MP4 or GIF with a history entry and toast. Options `gifFps`, `gifMaxWidth`, `recordShowClicks` (click rings, default on) on the Workflows tab. | macOS 15+, ScreenCaptureKit, AVFoundation, ImageIO | GIF verified by hand once; MP4 and click rings not yet. macOS 15+ only, hidden elsewhere. No audio. |
| Recording editor | dev | Edit on a recording toast opens a window with preview, play/pause, trim handles and a Beautify checkbox (saved effect settings). Export writes a new MP4, or GIF for GIF recordings; trim alone copies frames, Beautify re-encodes onto the still's canvas. | GIF / MP4 recording, Beautify | Not yet checked by hand. Needs the toast (captureToastSeconds > 0). No background shows black. Odd canvas sizes grow 1 px. |
| Expand canvas | beta | Editor toolbar button that adds 40 pt of white space on every side so you can draw outside the image; drawings move with the image and Cmd+Z undoes it. | Windowed editor | Window grows but does not shrink on undo. Shortcut E. |
| Editor settings bar | beta | Second toolbar row in the windowed editor with colour swatches from the user palette, a custom colour button and a size slider, kept in sync with all other ways of changing them. | Windowed editor | Every size change is saved as the new default. |
| Bendable arrows and lines | beta | Arrows and lines show a midpoint handle; dragging it bends them into a smooth curve with the arrowhead following the tangent. Undoable. | Tool system | None known. |
| Editor select tool | beta | Pointer button (V) in the editor toolbar that turns drawing off so existing objects can be selected, moved, bent or re-edited. | Windowed editor | None known. |
| Editor Cmd+Tab | beta | Edit windows stay on screen behind other apps like document windows; a Dock icon (and Cmd+Tab entry) appears only while editors are open and the app is in the background. Tray "Show Edit Windows" brings them forward. Clicking the toast picture opens Edit. | Windowed editor | Not yet checked by hand after the 2026-10-18 change. |
| Local certificate signing | beta | `CODE_SIGN_IDENTITY` plus `CODE_SIGN_HARDENED_RUNTIME=OFF` signs with a self-signed local certificate, giving every rebuild the same identity so macOS keeps the Screen Recording grant. | codesign, local Keychain certificate | Hardened runtime must stay off with a self-signed certificate or bundled Qt frameworks fail to load. |
| Scrolling capture | dev | Tray item or `SCROLL_CAPTURE` hotkey picks an area; a floating bar grabs it while you scroll (or Auto scrolls for you) and stitches one tall image, which goes through the normal capture actions. Option `scrollCaptureMaxHeight`, default 20000 px. | ScreenCaptureKit, macOS 15+ | Not yet checked by hand. Auto needs Accessibility. Moving content inside the area breaks matching. |
